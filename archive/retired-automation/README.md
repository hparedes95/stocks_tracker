# Automatización retirada

Código y pruebas conservados únicamente como archivo histórico del cambio de rumbo.
No forman parte del paquete instalado ni de la aplicación y sus imports antiguos
ya no están disponibles. No ejecutar estos scripts contra una instalación real.
El programa mantiene análisis, predicción, asesor y cartera manual; no envía órdenes.
Las tablas históricas se conservan para no borrar datos del usuario.
